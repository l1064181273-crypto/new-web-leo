# 桌面布局、播放器与沙盘修订

## 完成内容

- 删除 Music 中的 `Lo-fi Ambient / LOCAL`，播放器现在只有 Billboard 2024 年终前十。
- Music 保持原版单 iPod 构图，左右轮盘按钮切换歌曲，不显示右侧歌曲列表。
- 14 个桌面入口统一为 76×76、16px 圆角布局框。
- 布局框不绘制白色底板或外边框，只保留 Dock 风格图标自身的圆角与阴影。
- Resume 保留黄色备忘录图标；Field Notes 改为独立的深色笔记本图标。
- 桌面图标支持拖动，位置保存在 `leo-desktop-icon-layout-v1`；控制中心可重置布局。
- 移动端继续使用固定网格，避免拖动与页面滚动冲突。
- 工地外围道路加宽并内收路线，装载机工作包络缩小。
- 车辆轮胎与轮毂统一放入车轴组，只绕横向车轴滚动；车辆停车时轮胎停止。
- 沙盘增加程序化表面纹理、机械接触阴影、电影暗角和三组平滑镜头预设。

## 车辆验证

- 120 秒完整路线以 0.02 秒步长采样。
- 三车最小间距：11.6 场景单位。
- 车辆包络到围挡最小净距：0.594 场景单位。
- 越界样本：0。
- 运行时所有车辆 `wheelYaw` 为 0；停车车辆两次采样的 `wheelRoll` 均为 0。

## 当前游戏玩法

打开 `Herding Cats` 后点击 `PLAY NOW`。使用方向键或 WASD 移动角色，
靠近猫或物品时按 Space 互动，把猫送入画面标注的 Goal 区域。
游戏左下角提供静音和全屏按钮。

原版 Unity 构建会在手机浏览器显示兼容性提示；桌面 Chrome 是当前主要运行环境。
后续升级方案见 `NEXT-OPTIONS.md`。
