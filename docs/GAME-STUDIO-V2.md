# 牧猫庭院 · Game Studio V2

## 设计约定

基于正确功能版的 Herding Cats APP 扩展。第三方 Unity 游戏保留为“原版 Herding Cats”入口，其内核、关卡与美术没有被修改。默认体验是本地原创的“牧猫庭院”，全部场景由 SVG 像素图形绘制，无外部美术请求。

具体主题是一座可以散步的小庭院。访客的任务很简单：靠近猫咪、呼唤它们、带它们回右上角的小屋。游戏服务于私人桌面的轻松探索，不展示求职信息，也不虚构作者经历。

### 视觉

- 雾蓝 `#dceaf0`：桌面与游戏之间的过渡。
- 园墙 `#dbe6df`：安静的界面底色。
- 草叶 `#7ca887`：庭院与跟随路径。
- 苔绿 `#33584c`：文字、树篱和轮廓。
- 池水 `#82b5c1`：池塘与小面积冷色。
- 橘猫 `#d99554`：猫咪、小屋屋顶与主要行动。

标题用 Manrope / 系统中文，说明沿用系统中文，步数与关卡使用系统 monospace。唯一的视觉重点是会跟着脚步移动的原创像素猫群；界面保持清楚、安静，不使用霓虹、排行榜假数据或纯装饰性大数字。

布局选用“庭院 + 手边的小札”：桌面上场景在左，猫咪名单和目标在右；窄窗口中名单收在场景下方。庭院始终保持固定逻辑格，不因窗口大小改变规则。

## 玩法

1. 阳光门廊：两只亲人的猫，学习移动、呼唤和回家。
2. 绣球小径：三只不同性格的猫，穿过树篱；胆小猫需要更近，贪睡猫需要叫两次。
3. 雨后花园：四只猫，先拾取钥匙打开花园门，再接齐另一侧的猫回家。

鼠标或触屏点庭院格子会规划并走完可见路径；也可使用 WASD / 方向键或屏幕方向按钮。Space 呼唤，P / Esc 暂停。键盘只在已聚焦的庭院内处理，不监听全局键盘。猫咪会按可通行路线跟随，抵达门廊后自行排队回家。

“慢慢逛”没有失败压力；“步数挑战”把移动和呼唤计入预算。关卡完成后记录真实步数、用时和星数，可重玩或进入下一关。挑战预算用尽时给出重开、改为慢慢逛或返回关卡的选择。

## 生命周期与存档

- 当前 APP 失去 active、浏览器失焦、页面隐藏、切换到原版时暂停，回到时需手动继续。
- 本地保存经过版本校验的当前关卡、猫咪状态、设置、解锁进度与每关最佳成绩；损坏存档回退到新游戏，存储不可用时仍可玩。
- 本地游戏无需网络。原版需要联网；iframe 的 load 不等于 Unity 完成启动，界面不做虚假加载完成承诺。提供重试、打开源站与返回本地庭院。
- 第三方 iframe 无法安全暂停其内部引擎；APP 不活动时卸载 iframe，界面说明原版可能需要重载。

## 实现边界

所有规则、寻路、关卡、成绩和存档校验位于 `src/components/cat-game/`。React 负责界面和计时，SVG 负责渲染，纯函数负责状态更新。主桌面只需继续传入 `HerdingCatsApp active={...}`。

### 已知边界

- 本地进度仅保存在本浏览器，清理站点数据后会丢失；不是云存档。
- 原版跨域 Unity 内核不受本仓库控制，不能读取其进度、提供可靠的内部暂停或诊断其启动状态。卸载它是停止后台运行的方法。浏览器可能不会为跨域 iframe 网络错误触发 error，所以还提供超时说明、离线事件处理、始终可用的重试与源站链接；不会把网页 load 当成游戏启动成功。
- 小游戏是网格寻路与队伍收集，不是实时物理牧猫模拟。猫之间允许在拥挤格短暂交叠，渲染做轻微错位；树篱、池塘、关闭的门始终使用一致的碰撞规则。
