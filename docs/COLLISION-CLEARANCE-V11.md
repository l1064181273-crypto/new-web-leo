# Collision Clearance v11

## 用户报告

用户截图确认三处穿模：

1. 装载机车身进入渣土堆。
2. 外环卡车在转弯时穿过照明杆。
3. 板房附近工人的出生点或巡检路线进入墙体。

## 修复

- 装载机改为从土堆南侧接近，中心路线终点位于 `z = 1.70–1.72`；
  以车辆半长 `0.66` 计算，铲斗接触时车身仍停在土堆 `z = 2.4` 边缘之外。
- 四根照明杆从外环道路转角迁移到场内安全点，位置与车辆路线共用
  `sandbox/traffic.js` 中的结构化布局常量。
- 板房内的工人出生点移到门前；附近巡检路线改为沿板房正面横向移动。
- 新增运行时指标：
  - `minimumLampClearance`
  - `vehicle.lampClearance`
  - `loader.spoilClearance`
  - `workers.officeIntrusions`

## 验证

- 车辆完整 120 秒循环按 `0.01s` 步长采样，卡车到灯杆最小净距为
  `0.3726`，高于 `0.35` 的测试门槛。
- 装载机到土堆边缘的理论最小净距大于 `0.005`；六阶段实际截图采样
  为 `0.06–1.04`。
- 六个施工阶段的板房侵入人数均为 0。
- 六个施工阶段总碰撞违规均为 0。
- 单元测试 10 通过；全站 Playwright 35 通过、3 个按设计跳过、0 失败。

截图、阶段指标和日志位于 `artifacts/worker-posture-v10/`。
