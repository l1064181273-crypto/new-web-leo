## 本地数据并不加密

- 便签、存储恢复副本、TXT导出和JSON备份都是明文。能访问该浏览器配置、来源存储或导出文件的人或程序可能读取它们；不要存密码、访问密钥或敏感个人资料。
- “最近删除”是可恢复状态，不是安全擦除。完整JSON备份包含最近删除；之后永久删除便签也不会自动删除已经下载、复制或另存的备份。
- 本站没有便签云同步或作者收件功能。域名、端口、浏览器和设备变化不会自动迁移；清理站点数据可能丢失便签与恢复副本。重要内容应主动导出并自行保护文件。
- 本地保存不等于整站不联网，也不等于浏览器、扩展或系统层面的隐私保证。

## 跨标签保护不是事务性同步

共享存储hook保留本窗口成功读取 / 写入时的原始文本基线，在下一次写入前再次读取并比较；storage事件可提前提示冲突。发现外部内容变化或读取失败后，当前挂载保持内存模式，继续编辑和导出但不覆盖外部版本。关闭再重开才重新读取已保存内容。

真实双标签验证中：A持有77字符，B保存93字符；A显示冲突仍保留77。A临时编辑101字符并导出，B的93未被覆盖；A重开读取B；测试段撤回后两边恢复77。详细过程保留在维护者本地测试记录中；当前公开检查状态见[发布前检查](RELEASE-CHECK-2026-09-24.md)。

localStorage没有原子compare-and-set事务。另一标签仍可能恰好在检查与写入之间改变数据；本方案防止已观察到的顺序旧写入，不承诺消除一切同时竞争，也不自动合并内容。重要便签建议只在一个标签页编辑，冲突时先导出临时稿再关闭。

猫咪游戏使用独立存档机制；同版本多标签仍是最后写入，异版本记录有不覆盖保护。不能把便签的基线比较描述成所有APP的协同编辑能力。

## 第三方内容与消息边界

- 原版Unity只在访客主动载入后创建跨源iframe，切换应用 / 原版页或隐藏页面时卸载。本次未审计其运行时、下载内容、网络请求或隐私行为；iframe目前没有 `sandbox` 属性，并允许音频 / 全屏 / gamepad能力。跨源浏览器隔离不等于第三方程序已经经过审计。来源见[原版集成](../src/components/desktop/HerdingCatsApp.tsx)。
- Music使用Apple / iTunes外源试听，官方链接也会进入第三方服务。`preload="none"`是提示，不保证任何浏览器在点击播放前绝无请求；实际播放和打开链接会与外源通信。来源见[音频组件](../src/components/desktop/MusicApp.tsx)。
- 主站沙盘接收消息时校验当前iframe窗口和同源origin；沙盘校验父窗口来源及消息类型。独立HTML在 `file://` 下origin为 `null`，发送状态时使用 `*` 并对接收保留source / 类型检查，不能声称该路径与HTTP来源校验完全相同。消息仅承载运行状态 / 可见性，不包含便签正文。
- 外链HTTP 200、iframe load或页面连通只表示相应连接信号，不证明Unity引擎完成初始化或第三方内容可信。
