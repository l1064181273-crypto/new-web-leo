# Little Works · 从主体到交付 04

本轮只修改 Studio V2 沙盘的主楼与施工观察流程。外围场地、车辆路线及人员总数保留；没有推送或公开发布。

## 建筑方向

终点是一栋三层精品小写字楼。延续桌面微缩工地的材料感，主视觉是灰白水平收边、烟蓝落地窗与偏置的暖木内凹入口。侧后立面采用实墙和窗带，屋顶以女儿墙、楼梯出口、设备格栅及一角露台收口。

- 墙面 `#d9dfdb`，玻璃 `#648798`，金属框 `#354b56`。
- 入口木色 `#aa7955`，混凝土 `#adb4b0`，植物 `#627d67`。
- 沿用手札现有字体与钢蓝／黄铜配色，不引入外部字体、照片或材质下载。
- 夜景只点亮部分窗面，配有限的临窗家具剪影；不建设不可见的整栋室内空间。
- 入口雨棚、坡道和花池须避开现有装载机与工人的活动范围。

建筑的辨识度集中在入口与立面比例；不额外增加车辆、工人或真实灯光。保留原柱网及楼层，临时钢筋／脚手架在后期退出，避免“验收”时还呈现未收口的骨架。

## 工序

基坑 → 基础 → 一层 → 上层 → 主体封顶 → 外墙粉刷 → 门窗安装 → 装修与设备 → 竣工交付。

封顶对应主体检查，不等于竣工验收。粉刷通过墙面分区颜色变化表现；门窗和设备按施工进度显露，并没有模拟真实施工人员拿刷子、搬窗或办理验收。

自动循环 270 秒：前 88% 时间完成建设，88%–98% 留在成品状态（27 秒），最后 2% 平滑转入下一轮。手动时间轴、1–9 工序键、九站导览和存档使用同一组阶段。存档格式保持 v2，新存档写入 `constructionTimeline: "office-v4"`；无标记的旧自动观察按旧周期的生长／停留／转场相位迁移，避免原本已完工的存档恢复成粉刷阶段。旧手动进度保持不变。

## 性能策略

主楼采用共享 BoxGeometry 的五个实例批次：结构 354、立面 134、玻璃 39、近景细节 81、夜间窗光 14。共 622 个分件，其中永久件 328（新增 268）。窗面不使用实时折射、实时镜面或逐窗真实灯光。玻璃、室内细节和窗光不投射阴影；低画质及远景隐藏细节批次。施工进度不变时不更新主楼实例矩阵或墙色缓存。楼名字牌额外使用一张本地程序生成纹理。

永久结构置于实例数组前段，退场的 294 个临时件排在尾部。按当前可见范围裁短绘制数量，交付时结构批次只绘制 60 个永久件；倒拖时恢复绘制范围，不重新分配 GPU 缓冲区。

初始化时计算完整模型包围范围，避免后续楼层被错误裁剪。新增突出屋面加入雨滴遮挡，X/Z 区间归属预先计算。
