# 后续体验升级方案

## 沙盘视觉

### 方案 A：电影级工地模型（推荐）

增加轻量 SSAO/接触阴影、程序化法线纹理、选择性灯光 Bloom、雨天积水扩散和三组电影镜头。
优点是材质层次与空间感提升最明显；代价是需要按低中高三档画质控制后处理成本。

### 方案 B：建筑师桌面

强化“实体模型”方向：亚克力罩、比例尺、图签、激光刻字、蓝图剖面和点击区域说明。
视觉更克制、专业，性能影响小，适合作品集而不是纯游戏。

### 方案 C：活工地模拟

加入施工阶段时间轴、车辆任务调度、吊装目标、工人班组切换和环境音。
互动深度最高，但需要继续完善状态机、碰撞区域和移动端性能分档。

推荐先做 A 的光影材质，再叠加 B 的信息设计；C 作为后续独立版本。

当前已完成方案 A 的第一阶段：程序化粗糙度/凹凸细节、车辆与机械接触阴影、
电影暗角、全景/街道/塔吊镜头预设，同时保持约 59-60FPS。

## 当前游戏玩法

1. 打开桌面的 `Herding Cats`。
2. 点击 `PLAY NOW`。
3. 使用方向键或 WASD 移动角色。
4. 靠近猫或物品后按 Space 互动，把猫送到画面标注的 Goal 区域。
5. 左下角控制声音和全屏。

## 游戏改进

### 方案 1：忠实本地重制（推荐）

保留原版像素农场、牧猫目标和键位，重新实现为本地 Canvas/WebGL 游戏，
加入触屏摇杆、中文引导、暂停和本地进度。优点是不依赖第三方 Unity 服务。

### 方案 2：原版增强外壳

继续嵌入原版游戏，仅增加加载状态、网络失败重试、桌面成就和游戏说明。
工作量最小，但跨域限制使站点无法读取关卡和得分。

### 方案 3：个人网站主题关卡

在方案 1 基础上把地图改成实验室、旅行营地和摄影棚，猫会解锁照片与项目彩蛋。
与个人作品集结合最紧，但内容与美术制作量最大。

## 可借鉴的网页游戏机制

- [Cat Herder](https://ccecil.itch.io/cat-herder)：用激光笔吸引猫，适合加入“引导而非推撞”的操作。
- [Herding Cats](https://chicohaze.itch.io/herding-cats)：狗会把猫赶出目标区，骨头可以转移狗的注意力，
  适合做动态干扰和道具克制。
- [Cat Herder 9000](https://kellyarchiedev.itch.io/cat-herder-9000)：不同按键发出不同声音，
  猫不会完全听话，适合做猫的性格与随机反应。
- [Cat Cove Inn](https://loaflabs.itch.io/cat-cove-inn)：通过小游戏建立信任并帮助猫找到主人，
  适合增加长期收集与图鉴。
- [Catamagochi](https://kamilgrajdev.itch.io/catamagochi)：饥饿、饮水、清洁、快乐、每日奖励和装饰，
  适合扩展为轻量养成循环。
- [Cat Isle](https://domkegames.itch.io/cat-isle)：自主活动的猫、商店管理和场景装饰，
  适合增加沙盒建造与观察玩法。

推荐组合是“激光笔引导 + 猫性格差异 + 狗/骨头干扰 + 三分钟短局 + 猫图鉴”。
它能保持原版操作简单，同时增加策略、随机性和重复游玩价值。
