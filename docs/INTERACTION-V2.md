# 交互、图标与小游戏修订

> **历史记录边界：** 本文是原版及旧轮次的历史记录，保留当时结果，不代表当前 Studio V2 的最终验收、测试或发布状态。当前状态请见 [README.md](../README.md) 和 [发布前检查](RELEASE-CHECK-2026-09-24.md)。

## Findings

上一版在视觉之外加入了自行设计的多窗口管理，和参考的实际交互不同。
本轮用 Playwright 实测 Macxfolio 公开版，不再仅根据静态截图推测。

| 实测项目 | 参考结果 | 本轮处理 |
| --- | --- | --- |
| 单击桌面项目图标 | 打开内容浮层 | 保持单击，不改成双击 |
| 点击窗外桌面 | 关闭当前浮层 | 新增透明点击区域收起应用 |
| Escape | 退出当前浮层 | 新增键盘退出；相册弹层优先处理自己的 Escape |
| 三个彩色圆点 | 都退出当前浮层 | 不再对外提供最大化/缩放；红色结束实例，另两色收起 |
| Dock 切换 | 展示新的当前应用 | 只显示一个窗口，缓存其他应用状态 |
| 项目窗口 | 侧栏与顶栏相接，面包屑在顶栏 | 合并重复标题区，增加主页按钮 |
| 手机项目页 | 全屏，没有桌面栏和 Dock，底部左右切换 | 改为全屏和项目翻页控件 |

参考证据：`artifacts/interaction-v2/reference/*.json`、`*.png`。
其中 `control-red/yellow/green`、`escape-while-open`、`outside-click` 均显示浮层退出。
一次探测尝试点击被窗口遮住的 Music 图标而超时；改用实际可点击的 Dock 区域后完成探测。

缓存应用状态、关闭时清理音频/游戏等是本地实现的可靠性处理，不宣称是 Framer 内部实现。
私有 Framer 工程仍需登录，本轮未核对其中可能存在的定制。

## 图标

Daybook、Photography、Projects、Table Stories、Field Notes、Cinema、Arcade
都替换为已有非照片的 macOS 风格素材。个人照片和收藏封面只用于应用内容或用户选择的壁纸。

尝试使用指定图像生成接口制作图标，但该接口持续返回“正在生成”的同一等待图。
已通过 SHA-256 识别并排除该图，没有把占位图接入网站。
等待图只保留在 `artifacts/interaction-v2/pending-icons/` 用于解释尝试结果。
生产站点不向生成接口发请求。最终使用的是仓库自带的真实原生风格位图，不声称它们是新生成的素材。

## Orbit Breaker

游戏入口：桌面 **Arcade**，或 `/?app=games`。
在同一应用的“游戏收藏”标签中保留原来的四张游戏图片。

- 清爽浅色场地、玻璃质感砖块、球尾迹、碎片和连击反馈。
- 三关不同砖块排列和速度，每局三次生命，连击得分与通关奖励。
- Matter.js 处理碰撞；固定物理步长，限制长时间帧间隔，防止后台恢复时瞬间推进。
- 鼠标、左右方向键/A/D、触摸控制挡板，挡板击球位置影响出射角。
- 主动开始，不自动播放音效；音效使用短 Web Audio 合成音，可随时关闭。
- 暂停后物理状态冻结；失焦、页面隐藏、切到收藏、收起应用自动暂停。
- 改变屏幕尺寸重新计算逻辑场地，保持球的圆形与输入映射；返回待发球，不扣生命。
- 最高纪录本机保存；重新开始有确认；关闭应用清理 RAF、Matter 事件和音频上下文。

## 验证

- 14 个单元测试通过，其中 6 个使用 Matter 物理世界测试发球、挡板碰撞、
  砖块消除/连击、三次失误、三关通关/重开和时间步长。
- 28 个浏览器测试通过，覆盖桌面/手机、320px/768px 视口，以及之前的全部图片、笔记、联系功能。
- 游戏浏览器测试读取实际 canvas 像素，验证非空画面、显示/逻辑比例、移动挡板、
  真实得分、暂停帧不变、收藏切换和重开。未给生产游戏添加“跳关”或作弊接口。
- 首次物理测试夹具把球放进相邻砖块间，触发了两次碰撞；修正夹具为最底层砖块后，
  连击分数断言通过，没有降低游戏规则要求。
- Typecheck、Build 通过；Lint 0 错误，保留 7 条原有 Fast Refresh 警告。
- IDE 预览节流时，CSS 动画曾停在 opacity=0 首帧；改为第一帧即显示窗口，
  并用强制暂停/延迟动画的回归测试验证窗口仍可见。
