# 图标视觉尺寸与工人运动修复

## 图标

此前只统一了 76×76 的 DOM 布局框，没有补偿 PNG 文件内部的透明边距：

- GitHub、Photography、Projects 的有效像素约占画布 82%。
- Daybook、Table Stories 的有效像素约占画布 83%。
- Little Companion 的有效像素约占画布 85%。
- Resume、Music、Connect、Cinema 等接近 100%。

本轮按实际 alpha 边界分别设置缩放补偿。浏览器测试重新读取每张图片的像素透明度，
换算 CSS 缩放后的可见尺寸；14 个图标最终均落在 74–76px。
图标容器背景为透明、边框为 0，旧选择器残留的白色内阴影也已清除。

## 工人

搬运工原先同时使用正弦 X 位移和余弦 Z 位移，形成椭圆轨迹，看起来像原地绕圈。
本轮改为三角波直线路径：

- 巡逻人员沿安全通道直线往返。
- 搬运工沿物料通道直线往返。
- 仅在路径端点瞬时改变朝向，不连续自旋。
- 钢筋工、工具工和指挥员保持在工位，仅活动对应关节和工具。

所有 28 名工人的身体部件与工具继续使用 InstancedMesh。
