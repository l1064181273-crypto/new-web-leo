# 图标与沙盘视觉升级

## 桌面图标

- 移除统一图标容器的白色底板、边框和外圈阴影。
- 保留 76×76 布局尺寸，以图标素材自身的圆角和阴影呈现 Dock 风格质感。
- Field Notes 的深色笔记本图标仍保持独立识别，不与 Resume 重复。
- 拖动位置、刷新恢复和控制中心重置功能保持不变。

## 沙盘画面

- 给体素材质加入程序化 roughness/bump 纹理，减少纯色塑料感。
- 为挖掘机、卡车和装载机添加轻量接触阴影。
- 增加克制的电影暗角，不遮挡控制台和状态信息。
- 新增全景、街道、塔吊三组平滑镜头预设。
- 保持 Three.js r160 单 HTML 离线构建，不引入外部贴图或后处理依赖。

## 工人任务

28 名工人全部分配到五类任务：

- 3 名钢筋绑扎工：弯腰并操作钢筋工具。
- 9 名工具工：挥锤或操作手持工具。
- 3 名塔吊指挥员：双臂持续发出指挥信号。
- 11 名巡逻人员：沿安全通道往返行走。
- 2 名搬运工：抱着材料移动。

工人与工具仍使用 InstancedMesh。运行采样中 `motionChecksum` 持续变化，
桌面与手机测试帧率均约 59FPS。

## 约束结果

- 2202 个实例，约 28.9K triangles，约 130 draw calls。
- 车辆全周期最小间距 11.6。
- 车辆到围挡最小净距 0.594。
- 越界与运行时净距违规均为 0。
- 所有车辆轮胎 `wheelYaw` 为 0；停车车辆滚动角保持不变。

玩法调研与下一阶段建议见 `NEXT-OPTIONS.md`。
