# Worker Posture and Perimeter Roles v10

## 问题

- 巡检人员的腿和鞋原先绕 `Z` 轴左右摆动，体素腿会向外倾斜，形成罗圈腿。
- 外围 8 人由同一个循环放在 `z = 6.95` 的直线上，任务全部为巡逻，
  画面缺少明确的岗位目的。

## 修复

- 腿和鞋改为同一条髋部运动链，只绕本地 `X` 轴前后摆动。
- 鞋的位置由髋部距离和腿部角度共同计算，不再与小腿分离。
- 行走停止时摆角回到 0；手臂只在移动段与腿反向摆动。
- 增加“人员”镜头，桌面使用近景机位，手机使用更远的响应式机位。
- 外围人员分散到四边的安全通道，不占用车辆服务环路。

## 外围岗位

| 岗位 | 位置与职责 |
| --- | --- |
| Gate patrol | 北门巡检 |
| Gate banksman | 北门车辆引导 |
| Fence maintenance | 西侧围挡检修 |
| West traffic control | 西侧路口指挥 |
| Quality inspection | 南侧监理检查 |
| South supply runner | 南侧材料运输 |
| East road inspection | 东侧道路巡检 |
| East traffic control | 东侧路口指挥 |

这些人员继续受施工阶段控制：基坑阶段只保留必要门岗、巡检和交通人员，
基础与主体阶段逐步增加材料和检修岗位，验收阶段保留监理与安全岗位。
